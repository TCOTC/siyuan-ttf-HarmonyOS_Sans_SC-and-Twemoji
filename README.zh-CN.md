# 鸿蒙黑体 & Twemoji

鸿蒙黑体文件来自：[鸿蒙系统设计资源](https://developer.huawei.com/consumer/cn/design/resource/)/[开发者文档](https://developer.huawei.com/consumer/cn/doc/design-guides/font-0000001828772001)，由 .ttf 格式[转换](https://cloudconvert.com/ttf-to-woff)为 .woff 格式

Twemoji 字体文件来自：[TCOTC/twemoji-colr](https://github.com/TCOTC/twemoji-colr/)

### 注意

- 本插件可能与集市中的其他字体或 Emoji 插件不兼容，使用本插件时请禁用其他字体或 Emoji 插件。
- 本插件的字体优先于「设置 - 外观」中已选择的全局默认字体与编辑器字体。
- 选择「界面」时仅界面文字受影响，编辑器与文档保持原有字体。
- 选择「编辑器」时仅编辑器内容受影响，界面保持原有字体。
- 字重固定为 400，忽略设置中选择的字体字重；加粗与标题的字重不受影响。
- 行级字体不受本插件影响，单独为文本设置的字体优先显示。
- 中文字形仅支持简体，不支持繁体，因为鸿蒙黑体的繁体字形不完整。
